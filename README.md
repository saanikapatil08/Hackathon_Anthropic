# CareNav

Clinical and financial triage in one prompt. Tell CareNav what's wrong; it tells you whether to go to the **ER**, **Urgent Care**, or **Telehealth** based on clinical safety, your insurance coverage, and what's actually open right now.

Built for an Anthropic-sponsored hackathon (Health & Wellbeing track).

## What it does

1. You pick a persona (Alex on a high-deductible plan, or Jordan with a premium PPO).
2. You describe symptoms in plain English (e.g. "I sliced my hand while cooking").
3. CareNav runs your symptom + persona + facility data through Claude (with a deterministic mock fallback) and returns a 3-card **Decisiveness Dashboard**:
   - Recommended (green)
   - Worth considering (yellow)
   - Not recommended (red)

If the input mentions emergency keywords (chest pain, can't breathe, fainting, severe bleeding, ...), CareNav skips the LLM entirely and shows a full-screen **CALL 911** overlay.

## Tech stack

- Next.js 14 (App Router) + TypeScript
- Tailwind CSS + shadcn/ui primitives
- Anthropic SDK (Claude 3.5 Sonnet by default)
- Zod for response validation
- Hardcoded JSON for personas + facilities (no DB needed for the demo)

## Getting started

```bash
npm install

# Optional: enable real Claude triage
echo "ANTHROPIC_API_KEY=sk-ant-..." > .env.local

npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

> If `npm run dev` floods the terminal with `Watchpack Error (watcher): EMFILE: too many open files` (a macOS file-descriptor limit), run `WATCHPACK_POLLING=true npm run dev` instead.

If `ANTHROPIC_API_KEY` is not set (or Claude fails for any reason), CareNav falls back to a deterministic rule-based triage in [`app/lib/triage.ts`](app/lib/triage.ts) so the demo never breaks.

To use a different model:

```bash
CARENAV_MODEL=claude-3-5-haiku-20241022 npm run dev
```

## Demo script

| Scenario | Persona | Prompt | Expected |
| --- | --- | --- | --- |
| Cooking laceration, weekday afternoon | Alex (HDHP, Tue 2 PM) | "I sliced my hand while cooking, it's bleeding a lot." | Urgent Care recommended ($350-$490, deductible not met); ER not recommended (~4 hr wait, $2,500+). |
| Same wound, Sunday night | Jordan (PPO, Sun 8 PM) | Same prompt | Urgent Care closed; ER promoted because copay is just $250. |
| Cold/flu | Either | "Sore throat, cough, fever for 2 days." | Telehealth recommended ($0 or $0 copay); ER not recommended. |
| Emergency | Either | "I'm having chest pain and can't breathe." | Full-screen 911 overlay; no API call made. |

## Project layout

```
  lib/
    personas.json            # Hardcoded personas

  page.tsx                   # CareNav top-level page
components/
  TopNavBar.tsx              # Brand + persona dropdown + dark mode

  SymptomInput.tsx           # Textarea + examples + persona summary
  EmergencyOverlay.tsx       # Full-screen 911 warning

  TriageOptionCard.tsx       # Color-coded option card
  ui/                        # shadcn/ui primitives
lib/utils.ts                 # cn() helper
```

## Safety / disclaimers

CareNav is a hackathon prototype, not medical advice. The cost estimates are derived from hardcoded mock plans and facility charges; the clinical reasoning is generated by an LLM. Always call 911 in a real emergency.
